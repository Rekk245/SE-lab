# UML 图件说明

本目录七组 PNG/PlantUML 源码逐字节复制自实验二提交压缩包，未修改原图。

实验三保留了类图中的业务对象、四角色和状态机、原子入账及幂等语义。部署实现采用 Python Tkinter 与 SQLite，原组件图及完成审核时序图中的 Web、API、PostgreSQL 属于原设计，不是本次运行环境。

SQLite 通过 `BEGIN IMMEDIATE` 串行化写入，不执行 PostgreSQL 的 `SELECT ... FOR UPDATE`。事务内统一检查账本权限、内容版本和金额，写入唯一入账、份额、债务、审计及回执。

原图中 `Evidence.FILE`、可选择 A/B 的完整保留清理器、定时任务、附件服务器是尚未实现的部分。本次报价依据采用链接；保留策略保持 UNDECIDED。其他差异及实现决策在实验报告说明。
