# 实验三交付说明

- `实验报告.md`：主要可编辑报告，按真实实现与验证结果编写。
- `实验报告.pdf`：同内容的排版副本，修改 Markdown 后应重新导出 PDF。
- `UML/`：实验二原始七组 UML 图件及差异说明。
- `UI设计参考/`：实验二原始六张设计稿，供对照，不是运行截图。
- `code/`：程序、测试、构建脚本和 README，启动方式见该目录说明。
- `evidence/`：实际运行、测试、代码规模、风格和 Git 管理的文本证据。

提交前请本人逐行阅读和检查代码，确认报告中的实现选择并补充个人使用体会。桌面截图工具未能激活目标窗口，未提供或伪造实际界面截图；已完成程序启动及四角色六页面、两种窗口尺寸及新增交互检查。

报告仍明确列出数据保留、联网部署、附件上传等未实现或待确认的范围，不能据此宣称完整生产系统验收。
